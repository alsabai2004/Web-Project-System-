# 🏥 نظام إدارة عيادة طبية (Clinic Management System)

نظام إدارة عيادة طبية متكامل مكتوب بلغة Python باستخدام التخزين في ملفات JSON. يدعم النظام ثلاث واجهات رئيسية (سكرتير، طبيب، صيدلي) مع صلاحيات مختلفة لكل دور.

---

## 📋 نظرة عامة

نظام إدارة العيادة الطبية هو تطبيق Python يعمل في بيئة سطر الأوامر (Console) ويوفر واجهة شاملة لإدارة المرضى والمواعيد والأدوية:

- 📝 إدارة بيانات المرضى (إضافة، عرض، تعديل، حذف).
- 👨‍⚕️ واجهة الطبيب لتسجيل الحالة الصحية والأدوية.
- 💊 واجهة الصيدلي لعرض بيانات المرضى والأدوية.
- 📂 تخزين البيانات في ملفات JSON.
- 📅 تتبع مواعيد الزيارة والعودة.

---

## ✨ الميزات الرئيسية

### 📋 السكرتير (Secretary)
- **إضافة مريض**: إضافة مريض جديد مع جميع بياناته (الاسم، العمر، الجنس، رقم الهاتف، الواتساب، تاريخ الزيارة).
- **عرض مريض واحد**: عرض بيانات مريض محدد بالاسم.
- **عرض جميع المرضى**: عرض قائمة بجميع المرضى المسجلين.
- **حذف مريض**: حذف سجل مريض بالاسم.
- **تعديل بيانات مريض**: تحديث أي جزء من بيانات المريض.
- **حفظ البيانات**: حفظ البيانات في ملف JSON.
- **حذف الملف**: حذف ملف البيانات بالكامل.

### 👨‍⚕️ الطبيب (Doctor)
- **البحث عن مريض**: البحث عن مريض بالاسم.
- **تسجيل الحالة الصحية**: إدخال الحالة الصحية (جيد، متوسط، سيء).
- **إضافة الأدوية**: تسجيل الأدوية الموصوفة لكل مرض.
- **تحديد موعد العودة**: تسجيل تاريخ العودة للمريض.

### 💊 الصيدلي (Pharmacist)
- **عرض جميع المرضى**: عرض بيانات جميع المرضى والأدوية الموصوفة.

## 📖 دليل الاستخدام

### 1️⃣ الصفحة الرئيسية

```
================= MAIN PAGE =================
Press[1]: Go to the secretary
Press[2]: Go to the doctor
Press[3]: Go to the pharmacy
Press[4]: Set in the waiting room
=============================================
```

#### الخيارات:
- **1**: الانتقال إلى واجهة السكرتير.
- **2**: الانتقال إلى واجهة الطبيب.
- **3**: الانتقال إلى واجهة الصيدلي.
- **4**: وضع في غرفة الانتظار (رسالة تأكيد فقط).

### 2️⃣ واجهة السكرتير (Secretary)

```
=========== SECRETARY PAGE ===========
Press [1]: Add patient
Press [2]: View one patient informations
Press [3]: View all patients informations
Press [4]: Delete patient
Press [5]: Change the patient's informations
Press [6]: Go to the waiting room
Press [7]: Save the informations in a document
Press [8]: Delete the document
=======================================
```

#### الخيارات بالتفصيل:

**1. إضافة مريض (Add patient)**
- إدخال عدد المرضى المراد إضافتهم.
- لكل مريض:
  - الاسم الكامل.
  - العمر.
  - الجنس (male/female).
  - رقم الهاتف.
  - رقم واتساب.
  - رسوم التسجيل (يجب كتابة "ok" للتأكيد).
  - تاريخ الزيارة (يوم، شهر، سنة).

**2. عرض مريض واحد (View one patient)**
- إدخال الاسم الكامل للمريض.
- عرض جميع بياناته.

**3. عرض جميع المرضى (View all patients)**
- عرض جميع المرضى المسجلين مع بياناتهم الكاملة.

**4. حذف مريض (Delete patient)**
- إدخال الاسم الكامل للمريض المراد حذفه.
- حذف السجل بالكامل.

**5. تعديل بيانات مريض (Change patient's informations)**
- إدخال الاسم الكامل للمريض.
- اختيار الحقل المراد تعديله:
  - الاسم.
  - العمر.
  - الجنس.
  - الحالة الصحية.
  - الأدوية.
  - تاريخ الزيارة.
  - تاريخ العودة.
  - معلومات الاتصال.

**6. العودة لغرفة الانتظار (Go to waiting room)**
- العودة إلى الصفحة الرئيسية.

**7. حفظ البيانات (Save informations)**
- حفظ جميع البيانات في ملف `clinic_data.txt`.

**8. حذف الملف (Delete document)**
- حذف ملف البيانات بالكامل من النظام.

### 3️⃣ واجهة الطبيب (Doctor)

عند الدخول إلى واجهة الطبيب:
1. إدخال اسم المريض.
2. إدخال الحالة الصحية (good, so so, bad).
3. إدخال الأمراض والأدوية الموصوفة (اكتب `done` للإنهاء).
4. تحديد ما إذا كان هناك موعد عودة (yes/no).
5. إدخال تاريخ العودة إذا كان الجواب نعم.

### 4️⃣ واجهة الصيدلي (Pharmacist)

```
========== Pharmacist Interface ==========
Press[1]: Show all patient data
Press[2]: Back to main page
```

- **1**: عرض جميع المرضى مع تفاصيل الأدوية الموصوفة.
- **2**: العودة إلى الصفحة الرئيسية.

## 🔧 التخصيص والتطوير

### تغيير اسم ملف البيانات

يمكنك تغيير اسم ملف التخزين في المتغير `FILENAME`:

```python
FILENAME = "clinic_data.txt"  # قم بتغيير هذا الاسم
```

### إضافة حقول جديدة للمريض

1. أضف الحقل الجديد في دالة `add_patient()`.
2. أضف خيار التعديل في دالة `edit_patient()`.
3. قم بتحديث دالة `show_all_patients()` لعرض الحقل الجديد.

### إضافة صلاحيات جديدة

1. أضف واجهة جديدة في الصفحة الرئيسية.
2. أنشئ دالة جديدة للواجهة.
3. أضف الخيار في القائمة الرئيسية.
