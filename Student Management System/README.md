# نظام إدارة الطلاب (Student Management System - SMS)

نظام ويب بسيط لإدارة بيانات الطلاب باستخدام تقنيات الواجهة الأمامية (HTML, CSS, JavaScript) والتخزين المحلي للمتصفح (LocalStorage). يسمح النظام بعمليات الإضافة، العرض، والحذف للطلاب.

## نظرة عامة

نظام إدارة الطلاب هو تطبيق ويب متكامل يوفر واجهة سهلة الاستخدام للقيام بالعمليات الأساسية على بيانات الطلاب:
- إضافة طلاب جدد مع تفاصيلهم (ID، الاسم، القسم، المستوى، المعدل).
- عرض قائمة بجميع الطلاب المسجلين.
- حذف طالب باستخدام رقمه المعرف (ID).
- لوحة تحكم رئيسية تعرض عدد الطلاب الكلي.

## الميزات الرئيسية

- **نظام مصادقة**: تسجيل دخول بحساب افتراضي (username: `admin`, password: `1234`).
- **واجهة سهلة**: تصميم بسيط وجذاب مع شريط تنقل واضح.
- **إضافة طالب**: إدخال بيانات الطالب مع التحقق من عدم تكرار الرقم المعرف (ID).
- **عرض جميع الطلاب**: جدول يعرض كامل بيانات الطلاب المسجلين.
- **حذف طالب**: حذف سجل الطالب باستخدام رقمه المعرف.
- **تحديث فوري**: يتم تحديث عدد الطلاب تلقائياً عند الإضافة أو الحذف.
- **تخزين محلي**: استخدام LocalStorage لحفظ البيانات بشكل دائم في المتصفح.
- **حماية الصفحات**: يتم إعادة توجيه المستخدم غير المسجل إلى صفحة تسجيل الدخول تلقائياً.

## التقنيات المستخدمة

- **HTML5**: هيكل الصفحات وتنظيم المحتوى.
- **CSS3**: تنسيق وتصميم واجهات المستخدم.
- **JavaScript**: منطق التطبيق والتفاعل مع البيانات.
- **LocalStorage API**: تخزين بيانات الطلاب محلياً في المتصفح.

## دليل الاستخدام

### 1. تسجيل الدخول

1. افتح ملف `index.html`.
2. أدخل بيانات الدخول:
   - **Username**: `admin`
   - **Password**: `1234`
3. انقر على زر **"دخول"**.

### 2. الصفحة الرئيسية (Home)

- تعرض **عدد الطلاب** المسجلين في النظام.
- يمكنك التنقل عبر شريط التنقل العلوي إلى الصفحات الأخرى.

### 3. إضافة طالب (Add)

1. انتقل إلى صفحة **"➕ إضافة"**.
2. املأ جميع الحقول:
   - **رقم الطالب (ID)**: يجب أن يكون فريداً.
   - **الاسم الكامل**.
   - **القسم**.
   - **المستوى** (رقم من 1 إلى 4).
   - **المعدل** (رقم من 0 إلى 4).
3. انقر على زر **"💾 حفظ الطالب"**.
4. ستظهر رسالة تأكيد بإضافة الطالب، وسيتم تحديث عدد الطلاب تلقائياً.

### 4. عرض جميع الطلاب (View)

- انتقل إلى صفحة **"📋 عرض"**.
- ستظهر قائمة بجميع الطلاب المسجلين في جدول يحتوي على: ID، الاسم، القسم، المستوى، المعدل.
- إذا لم يكن هناك طلاب، ستظهر رسالة "لا يوجد طلاب حالياً".

### 5. حذف طالب (Delete)

1. انتقل إلى صفحة **"🗑️ حذف"**.
2. أدخل **رقم الطالب (ID)** الذي ترغب في حذفه.
3. انقر على زر **"حذف"**.
4. ستظهر رسالة:
   - ✅ **"تم حذف الطالب بنجاح"** إذا تم العثور على الرقم.
   - ❌ **"لا يوجد طالب بهذا الرقم"** إذا كان الرقم غير موجود.
5. سيتم تحديث عدد الطلاب تلقائياً بعد الحذف.

### 6. تسجيل الخروج

- انقر على زر **"🚪 خروج"** في أي صفحة لتسجيل الخروج والعودة إلى صفحة تسجيل الدخول.
