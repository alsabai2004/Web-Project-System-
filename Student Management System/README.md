# 🎓 نظام إدارة الطلاب (Student Management System - SMS)

نظام ويب متكامل لإدارة بيانات الطلاب باستخدام تقنيات الواجهة الأمامية (HTML, CSS, JavaScript) والتخزين المحلي للمتصفح (LocalStorage). يسمح النظام بعمليات الإضافة، العرض، والحذف للطلاب مع نظام مصادقة بسيط.

---

## 📋 نظرة عامة

نظام إدارة الطلاب هو تطبيق ويب متكامل في عدة صفحات يوفر واجهة سهلة الاستخدام للقيام بالعمليات الأساسية على بيانات الطلاب
- ✅ إضافة طلاب جدد مع تفاصيلهم (ID، الاسم، القسم، المستوى، المعدل).
- ✅ عرض قائمة بجميع الطلاب المسجلين في جدول منظم.
- ✅ حذف طالب باستخدام رقمه المعرف (ID).
- ✅ لوحة تحكم رئيسية تعرض عدد الطلاب الكلي.
- ✅ نظام مصادقة بسيط للدخول إلى النظام.

---

## ✨ الميزات الرئيسية

- 🔐 **نظام مصادقة**: تسجيل دخول بحساب افتراضي (`username: admin`, `password: 1234`).
- 🎨 **واجهة جذابة**: تصميم عصري بألوان داكنة مع تباين جميل.
- ➕ **إضافة طالب**: إدخال بيانات الطالب مع التحقق من عدم تكرار الرقم المعرف (ID).
- 📋 **عرض جميع الطلاب**: جدول يعرض كامل بيانات الطلاب المسجلين.
- 🗑️ **حذف طالب**: حذف سجل الطالب باستخدام رقمه المعرف.
- 🔄 **تحديث فوري**: يتم تحديث عدد الطلاب تلقائياً عند الإضافة أو الحذف.
- 💾 **تخزين محلي**: استخدام LocalStorage لحفظ البيانات بشكل دائم في المتصفح.
- 🛡️ **حماية الصفحات**: يتم إعادة توجيه المستخدم غير المسجل إلى صفحة تسجيل الدخول تلقائياً.

---

## 🛠️ التقنيات المستخدمة

| التقنية | الاستخدام |
|---------|-----------|

## 📖 دليل الاستخدام

### 1️⃣ تسجيل الدخول

1. افتح ملف `index.html`.
2. أدخل بيانات الدخول:
   - **Username**: `admin`
   - **Password**: `1234`
3. انقر على زر **"دخول"**.

#### مثال:
![تسجيل الدخول](https://via.placeholder.com/400x200/1a1a2e/e94560?text=Login+Page)

---

### 2️⃣ الصفحة الرئيسية (Home)

- تعرض **عدد الطلاب** المسجلين في النظام.
- يمكنك التنقل عبر شريط التنقل العلوي إلى الصفحات الأخرى.

#### مثال:
```

🏠 لوحة التحكم
مرحباً بك في نظام إدارة الطلاب
عدد الطلاب المسجلين: 5

```

---

### 3️⃣ إضافة طالب (Add)

1. انتقل إلى صفحة **"➕ إضافة"**.
2. املأ جميع الحقول:
   - **رقم الطالب (ID)**: يجب أن يكون فريداً.
   - **الاسم الكامل**.
   - **القسم**.
   - **المستوى** (رقم من 1 إلى 4).
   - **المعدل** (رقم من 0 إلى 4).
3. انقر على زر **"💾 حفظ الطالب"**.
4. ستظهر رسالة تأكيد بإضافة الطالب، وسيتم تحديث عدد الطلاب تلقائياً.

#### مثال:
```

➕ إضافة طالب جديد
رقم الطالب (ID): 2024001
الاسم الكامل: أحمد محمد
القسم: علوم الحاسوب
المستوى (1-4): 3
المعدل (0-4): 3.75

✅ تمت إضافة الطالب
ID: 2024001
الاسم: أحمد محمد
القسم: علوم الحاسوب
المستوى: 3
المعدل: 3.75

```

---

### 4️⃣ عرض جميع الطلاب (View)

- انتقل إلى صفحة **"📋 عرض"**.
- ستظهر قائمة بجميع الطلاب المسجلين في جدول يحتوي على: ID، الاسم، القسم، المستوى، المعدل.
- إذا لم يكن هناك طلاب، ستظهر رسالة "📭 لا يوجد طلاب حالياً".

#### مثال:
```

📋 قائمة الطلاب

ID الاسم القسم المستوى المعدل
2024001 أحمد محمد علوم الحاسوب 3 3.75
2024002 سارة علي هندسة برمجيات 2 4.00
2024003 خالد عبدالله نظم المعلومات 4 3.50

```

---

### 5️⃣ حذف طالب (Delete)

1. انتقل إلى صفحة **"🗑️ حذف"**.
2. أدخل **رقم الطالب (ID)** الذي ترغب في حذفه.
3. انقر على زر **"حذف"**.
4. ستظهر رسالة:
   - ✅ **"تم حذف الطالب بنجاح"** إذا تم العثور على الرقم.
   - ❌ **"لا يوجد طالب بهذا الرقم"** إذا كان الرقم غير موجود.
5. سيتم تحديث عدد الطلاب تلقائياً بعد الحذف.

#### مثال:
```

🗑️ حذف طالب
أدخل رقم الطالب (ID): 2024002

✅ تم حذف الطالب بنجاح

```

---

### 6️⃣ تسجيل الخروج

- انقر على زر **"🚪 خروج"** في أي صفحة لتسجيل الخروج والعودة إلى صفحة تسجيل الدخول.

## 🔧 التخصيص والتطوير

### تغيير بيانات تسجيل الدخول

يمكنك تغيير اسم المستخدم وكلمة المرور في ملف `script.js` داخل دالة `login()`:

```javascript
if (username === "admin" && password === "1234") {
    // قم بتغيير admin و 1234 إلى ما تريد
}
```

إضافة حقول جديدة للطالب

1. أضف الحقل الجديد في صفحة add.html داخل النموذج.
2. قم بتعديل دالة addStudent() في script.js لجلب القيمة الجديدة.
3. أضف الحقل الجديد إلى كائن student الذي يتم حفظه.
4. قم بتعديل دالة displayStudents() لعرض الحقل الجديد في الجدول.

تغيير ألوان التصميم

يمكنك تغيير الألوان في أقسام <style> في كل صفحة:

```css
body {
    background-color: #0f3460;  /* تغيير لون الخلفية */
}
.logo {
    color: #e94560;  /* تغيير لون الشعار */
}
```

مسح جميع البيانات

لحذف جميع البيانات المخزنة:

1. افتح أدوات المطور (F12).
2. اذهب إلى Application → Local Storage.
3. انقر بزر الماوس الأيمن واختر "Clear".

🚀 كيفية التشغيل

المتطلبات

· متصفح ويب حديث (يدعم LocalStorage).
· لا يتطلب خادم ويب للعمل.

الخطوات

1. تحميل الملفات:
   قم بتحميل جميع الملفات في مجلد واحد.
2. فتح المتصفح:
   افتح ملف index.html في متصفحك.
3. تسجيل الدخول:
   استخدم بيانات الدخول: admin / 1234
4. بدء الاستخدام:
   · استخدم شريط التنقل للتنقل بين الصفحات.
   · أضف طلاباً جدد، اعرضهم، أو احذفهم.

📝 ملاحظات للمطورين

· جميع البيانات تُخزن في localStorage تحت المفتاح "students".
· حالة تسجيل الدخول تُخزن في localStorage تحت المفتاح "loggedIn".
· الصفحات المحمية: يتم التحقق من حالة تسجيل الدخول في كل صفحة وإعادة التوجيه تلقائياً.
· لا يحتاج إلى خادم ويمكن تشغيله مباشرة من المتصفح.
· جميع الصفحات تشترك في ملف script.js واحد.
